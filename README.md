# GitHub User Activity CLI
A simple command-line application that fetches and displays recent GitHub activity for a specified user using the GitHub API.

## Requirements

- Python 3.x

## Usage

Run the program from your terminal by providing a GitHub username as an argument:

```bash
python github_activity.py torvalds
```

Replace `torvalds` with the GitHub username you want to check.


## Example Output

```text
Pushed commits to: torvalds/linux
Pushed commits to: torvalds/linux
Pushed commits to: torvalds/linux
DeleteEvent torvalds/linux
Pushed commits to: torvalds/linux
```
